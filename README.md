# Proxy6 Desktop (Windows)

Десктопная версия приложения **Proxy6 Hub v1.0.44** (`net.proxy6.hub`).
Интерфейс — оригинальный (взят из APK без изменений), нативный Android-слой заменён версией для Windows.

## Как получить .exe

**Вариант 1 — локально (≈5 минут).** Нужен [Node.js LTS](https://nodejs.org).
Распакуйте архив и запустите `build.bat`. Результат в папке `dist\`:

- `Proxy6-Setup-1.0.44.exe` — установщик
- `Proxy6-Portable-1.0.44.exe` — портативная версия без установки

**Вариант 2 — без установки чего-либо.** Загрузите папку в репозиторий GitHub →
вкладка *Actions* → *Build Windows .exe* → *Run workflow* → скачайте артефакт `Proxy6-windows`.

Запуск без сборки (для проверки): `npm install` → `npm start`.

## Что перенесено

| В Android-версии | В версии для ПК |
|---|---|
| Весь интерфейс: покупка, прокси, заказы, платежи, баланс, FAQ, тикеты, язык RU/EN | Тот же код, 1:1 |
| Привязка аккаунта, баланс, заказы, список прокси | Работают с тем же сервером |
| Подключение HTTP / SOCKS5 прокси (логин/пароль) | Локальный форвардер `127.0.0.1` + системный прокси Windows |
| Доменные правила (direct / proxy, `*.ru`, `vk.com`, CIDR), RU-пресет | Те же правила, применяются сразу, без переподключения |
| Журнал подключений, статус, диагностика | Есть |
| Уведомления об окончании прокси | Уведомления Windows: за 3 дня, за 1 день и при истечении |
| Буфер обмена, открытие ссылок | Есть |
| Работа в фоне | Окно скрывается в трей, пока есть подключение |

Настройки и данные хранятся в `%APPDATA%\Proxy6`.
Системные настройки прокси Windows при отключении/выходе возвращаются как были;
если программа аварийно завершилась, они восстановятся при следующем запуске.

## Отличия от Android (и почему)

1. **Маршрутизация по приложениям (белый/чёрный список) недоступна.** На Android это делает VpnService.
   В Windows для этого нужен драйвер виртуального адаптера (Wintun) и отдельное ядро tun2socks.
   Вместо этого прокси применяется ко всей системе: браузеры и программы, использующие системный прокси.
   Программы со своим сетевым стеком (часть игр, торрент-клиенты) системный прокси игнорируют.
2. **Push-уведомления с сервера (FCM) недоступны** — это сервис Google для Android. Напоминания об окончании работают локально.
3. **Автообновление (OTA) отключено.** Новая версия — новая сборка.
4. **Интерфейс мобильный** — окно по умолчанию узкое (480×860), его можно менять; масштаб `Ctrl +/−/0`, `F5` — перезагрузка.

## Первый запуск

Настройки с телефона перенести нельзя (они лежат на самом телефоне, а не в APK).
Привяжите аккаунт заново (*Account → Sign in*): заказы, баланс и прокси подтянутся с сервера.

## Структура

```
main.js           окно, трей, мост Android→Windows, подключение/отключение
preload.js        объект window.AndroidProxy для оригинального интерфейса
lib/proxy-core.js локальный форвардер (HTTP CONNECT + обычный HTTP)
lib/upstream.js   клиенты HTTP-прокси и SOCKS5 с авторизацией
lib/rules.js      доменные правила
lib/system-proxy.js  системный прокси Windows + аварийное восстановление
lib/expiry.js     уведомления об окончании
app/              оригинальный веб-интерфейс из APK
test/core.test.js автотесты ядра (npm test)
```
